# Glory Stylo 0.22.0

First registry publication of the maintained Stylo engine used by Glory and Apace.

- Preserves source commit `78734bf554bb40af9dc11c0eedbe724f6055697c`, including
  Servo text-fill and background-clip behavior absent from upstream Stylo 0.22.0.
- Publishes the complete shared type graph under owned `glory-` package names.
  Existing Rust library names, public interfaces and behavior remain unchanged.
- Requires Rust 1.95 and resolver 3. Internal path dependencies carry matching
  registry versions; consumers need no Git dependency or global Cargo patch.
- Retains upstream history, copyright and MPL-2.0 licenses.

Source compilation, engine tests and archive provenance checks gate publication.
Gecko integration is not an independently supported Glory target.
